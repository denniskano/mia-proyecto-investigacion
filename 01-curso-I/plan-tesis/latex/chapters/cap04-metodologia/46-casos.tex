El criterio de elección es el dominio (pagos, cuentas, préstamos), no el Anexo~F. Ese anexo solo
fija el formato con un ejemplo, \textit{Payment Initiation}: el \texttt{POST /payment-orders} del
contrato frente al \Behavior{} \texttt{Initiate}.

De cada caso se guarda el id de instancia, el YAML, el extracto BIAN, la tabla de pares y los
cuatro números. Cuántos casos se corren, y cuáles, no se cierra en Guía~1 (\Cref{sec:alcances}).
