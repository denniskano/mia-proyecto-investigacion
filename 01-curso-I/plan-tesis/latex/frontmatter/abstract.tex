\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Group~10 asks a practical question: does a bank's OpenAPI contract describe the same capability as
the BIAN Service Domain chosen as reference? The check, when it happens at all, is still a manual
review.

We specify a scoring procedure rather than a production tool. SemanticScore (S), StructuralScore
(E) and CoverageScore (C) feed an AlignmentScore for each pair
\texttt{OpenAPI contract $\times$ Service Domain}. Appendix~C holds the consistency matrix.

Guide~1 stops at design. We do not ship code, run a bank pilot, or score live API security
(§\ref{sec:alcances}).
